Pastel AI - Fast Launch Guide

1. Single-Command Install & Run (Terminal):
   pip install -r requirements.txt && python desktop_app.py

2. One-Click Automated Launcher:
   run.bat

3. Run Standalone Executable Directly (No Python needed):
   dist\PastelAI\PastelAI.exe

4. Move to Another Laptop (One-Line Setup in PowerShell):
   winget install Ollama.Ollama -e --accept-source-agreements --accept-package-agreements && ollama run qwen2.5:3b && .\dist\PastelAI\PastelAI.exe
